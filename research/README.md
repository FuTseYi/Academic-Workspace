# Research · 研究探索

整理研究方向、选题思路、公开文献与项目调研，让研究过程能够持续迭代、查阅和复盘。

## 建议分类

| 方向 | 示例内容 |
| --- | --- |
| Project Exploration | 项目背景、研究问题、可行性和待核验项 |
| Literature Review | 论文笔记、方法对比、参考文献 |
| Research Planning | 研究假设、技术路线、实验设计 |
| Supervisor Exploration | 公开研究方向及待了解的问题 |

## 研究笔记的基本原则

明确区分 **已验证事实、个人判断、后续需要核实的事项**。避免根据项目标题推断实验条件、招募状态或学术质量。

这里暂不公开个人 AS 选择进展或平台内的非公开项目详情。
