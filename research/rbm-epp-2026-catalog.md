## 重点关注项目与 EPP 操作备忘

以下是根据**项目标题、页面领域标签**，结合个人关注的 **AI、机器人与自主系统、具身智能、计算机视觉、边缘部署、工业场景**进行的**初筛判断**。它反映的是“方向/经验适配”，不是已核验的项目技术方案、导师实力、可加入程度或实际产出。

### 3.1 第一组：技术方向与工程能力高度贴近

| # | 项目简称 | 适配判断（推测，不是平台事实） | 加入前需重点核实 |
|---:|---|---|---|
| **28** | Cyborg Insects for Search and Rescue | 具身智能 + 自主控制 + 搜救任务的交叉，适合探索感知、规划与边缘计算协同 | 仿生昆虫硬件/实验条件；安全、伦理要求；核心研究到底聚焦控制还是感知 |
| **38** | Tactile Perception for Humanoid Robot Feet | 涉及具身感知与机器人软硬件协同，研究特征突出 | 是否有机器人平台、足底传感器和真实实验条件；个人可负责的独立模块 |

### 3.3 初步联系策略

**优先考察组合（主观建议）**：

1. **以具身智能研究为目标**：先阅读 #28、#38、#68；随后以 #58 为算法方向补充。
2. **以工业 AI / 边缘部署形成明确成果为目标**：先看 #15、#48、#37；随后比较 #64、#75。
3. **以视觉感知 + 真实世界验证为目标**：先看 #31、#41；随后视兴趣比较 #51、#63。

**联系前的通用核实问题**：项目的最小可交付成果是什么？实际研究问题与项目标题是否一致？已有硬件/数据/算力有哪些？对新成员的研究技能要求是什么？是否有明确的 Supervisor、会议节奏和分工？是否仍开放加入？若考虑毕业论文或后续申请研究职位，能否承担可独立验证、可复现且有署名规则的研究子任务？

> **关键提醒**：以上排序不包含导师信息、完整 Proposal、团队反馈、资源保障或真正的招募名额，现阶段只适合用来决定“先点开哪些项目、先联系谁”，不能据此认定项目优劣。

### 4.2 项目可见性与协作权限

- **Discoverable（默认）**：其他用户可能看到用于检索与匹配的有限项目信息，**但只有项目成员能打开完整 Proposal**。
- **Private**：项目不进入 Discover Projects；可见性日后可修改。
- 「Similar / Complementary Projects」分别帮助识别问题方向相近、或能力互补的项目；结果取决于证据，不保证每个项目都有推荐。

依据：官方教程 pp. 5、16。

### 4.3 邀请 Project Supervisor（PS）

- 教程说明自动推荐功能当时处于暂停状态；可以在 **Managed PS Pool** 中通过姓名、邮箱、CFT/RBM 或关键词搜索，阅读完整简介。
- PS 候选人可按优先级管理（教程描述选择 1–3 人）；邀请**按优先顺序依次发出**：前一位拒绝后才会邀请下一位，第一位接受的人成为 primary PS。
- 教程还展示 PS 当前 active project supervision load。
- 在平台发起 `Invite PS` **不等于事先获得对方同意**。如先前 RBM 通知强调，必须先沟通，再发送邀请。

依据：官方教程 p. 10。

### 4.4 正式 Proposal 的最低结构要求

根据官方教程 pp. 17–19，**正式提交自己的 Problem Proposal** 前应检查：

- [ ] Proposal 的 **Title、Background、Core Problem Statement** 已完整填写。
- [ ] 已确认 **Project Supervisor** 信息。
- [ ] **至少 3 个 Sub-project** 已创建（教程 p. 18 要求 3 个）。
- [ ] **每个 Sub-project 都有 Title 和对应 Thrust**。
- [ ] 最新 Proposal 迭代已经保存。
- [ ] 已查看 AI Evaluation 反馈（如有）。
- [ ] 提交所需支持材料已准备妥当。
- [ ] 点击 **Submit** 并确认提交。

**区分两种行动**：浏览、咨询或申请加入别人的项目，**不是**“自己创建正式 Proposal 并提交”；不能把“3 个 Sub-project”的自建正式提案要求直接当作浏览/加入的门槛。

### 4.5 版本、会议纪要与技术支持

- **Version History**：每次有效保存创建版本，可比较修改前后内容；编辑支持 `Ctrl+S` / `Command+S`（pp. 9、11）。
- **Meeting Minutes**：支持上传会议记录或导入腾讯会议云录制内容，AI 可整理决策、行动项与修订方向，之后仍可人工修改确认（p. 12）。
- **AI Evaluation**：分析最新 Proposal 的优点、风险、证据和修改建议；属于辅助反馈，并非人工审批结果（p. 13）。
- **技术问题**：从右上角 `Support` 反馈，尽量附复现步骤、截图和项目相关信息；教程提供技术支持邮箱 `rbm-epp@hkust-gz.edu.cn`（p. 4）。
