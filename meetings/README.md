# Meetings · 组会与汇报

用于持续管理组会和学术汇报：从会前准备，到会中讨论，再到会后行动项。

## 建议工作流

1. **Before · 会前**：讨论目标、背景资料、观点、待询问的问题。
2. **During · 会中**：观点与反馈、现场记录、待证实事项。
3. **After · 会后**：确认的结论、后续任务、下次需要跟进的内容。

## 文档命名

使用 `YYYY-MM-DD-topic.md`（例如 `YYYY-MM-DD-ucmp-group-meeting.md`），按日期组织，避免把多次组会混在一个超长文件里。

## 可复用的组会模板

```markdown
# YYYY-MM-DD｜组会主题

## 会前准备
- 目标：
- 资料：
- 待讨论问题：

## 会议记录
- 讨论：
- 反馈：
- 待核实：

## 结论与行动项
- [ ] 任务｜负责人｜期限
```

> 目前只提供通用模板。实际会议纪要和讨论材料将在确认适合存储的访问权限后再导入。
