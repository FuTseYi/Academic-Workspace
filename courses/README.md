## 组织约定

- 一门课程一个目录或主页面，按需要增加 `assignments/`、`notes/`、`references/` 等子目录。
- 有日期的笔记与作业尽量使用 `YYYY-MM-DD-topic.md` 命名。
- 不复制相同内容到多个分类：课程页面可以链接到 Meetings 或 Research 对应记录。
- 每次新增资料后，先更新课程索引；重要页面再加入全站侧边栏。
